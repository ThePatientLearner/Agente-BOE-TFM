# Alcance de la copia pública del TFM

Copia del núcleo de Agente BOE preparada el 4 de octubre de 2026. Incluye backend modular completo, web, pruebas, configuración de ejemplo, Docker, scripts y documentación académica.

Se excluyen CV y sus PDF, cuadernos HTML personales y panel de estudio, claves y configuración privada, datos operativos y el historial Git original. La autenticación de BoeBot, sus permisos y pruebas permanecen incluidos. El material privado de estudio no es necesario para ejecutar el núcleo ni la demo del TFM. La web original sigue disponible en https://agenteboe.com/.

Esta copia no posee las claves o base de datos de producción. Para generar nuevos datos se necesita una clave propia y PostgreSQL; las pruebas unitarias no necesitan servicios externos.
